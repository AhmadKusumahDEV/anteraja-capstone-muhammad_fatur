================================================================================
API DOCUMENTATION: INBOUND SORTING (F-06)
================================================================================
Kumpulan Endpoint API untuk fitur Inbound Sorting & Fleet Acknowledge.
Base URL: http://localhost:8000/api/v1

** SEMUA ENDPOINT DI BAWAH INI WAJIB MENGGUNAKAN HEADER:
Authorization: Bearer <ACCESS_TOKEN>
Accept: application/json
Content-Type: application/json
--------------------------------------------------------------------------------

────────────────────────────────────────────────────────────────────────────────
1. GET LIST INBOUND MANIFESTS (Tabel Antrean Manifest Masuk)
────────────────────────────────────────────────────────────────────────────────
Deskripsi : Menampilkan daftar manifest armada yang MENUJU ke Hub Admin yang sedang login (otomatis terfilter berdasarkan JWT Token).
Method    : GET
Endpoint  : /inbound/manifests

[Query Parameters] (Optional)
- status : string -> Filter berdasarkan status manifest (Contoh: "MENUNGGU_KEDATANGAN" atau "SUDAH_DITERIMA")

[Response Success (200 OK)]
{
  "success": true,
  "data": [
    {
      "manifest_code": "MNF-INB-20261001-8017",
      "type": "INBOUND_FEEDER",
      "origin_hub_name": "Bandung Pusat Hub",
      "vehicle_type": "TRUCK_WINGBOX",
      "status": "MENUNGGU_KEDATANGAN",
      "total_packages": 125,
      "eta_timestamp": "2026-10-01 15:41:32",
      "created_at": "2026-10-01 12:41:32"
    }
  ]
}

[Response Error Hak Akses (403 Forbidden)]
{
  "success": false,
  "message": "Admin tidak memiliki akses ke Hub manapun."
}

────────────────────────────────────────────────────────────────────────────────
2. POST ACKNOWLEDGE MANIFEST (Tombol Terima / Konfirmasi Armada)
────────────────────────────────────────────────────────────────────────────────
Deskripsi : Menyetujui dan menerima manifest yang baru datang. Endpoint ini akan meng-update manifest menjadi SUDAH_DITERIMA, memindahkan semua resi (paket) masuk ke Hub, dan otomatis menghitung SLA (Tenggat Waktu) per resi.
Method    : POST
Endpoint  : /inbound/manifests/{manifest_code}/acknowledge

[URL Parameters]
- manifest_code : string -> Kode manifest armada yang akan diterima.

[Request Body]
(KOSONG) - Endpoint ini tidak membutuhkan body.

[Response Success (200 OK)]
{
  "success": true,
  "message": "Manifest berhasil diterima, seluruh paket masuk ke Hub Anda.",
  "data": {
    "manifest_code": "MNF-INB-20261001-8017",
    "status": "SUDAH_DITERIMA",
    "updated_at": "2026-10-02 08:30:00"
  }
}

[Response Error Status Tidak Valid (400 Bad Request)]
// Jika tombol "Terima" diklik ulang padahal statusnya sudah diterima sebelumnya.
{
  "success": false,
  "message": "Manifest ini tidak bisa di-terima karena status saat ini: SUDAH_DITERIMA"
}

[Response Error Bukan Tujuan Hub (404 Not Found)]
{
  "success": false,
  "message": "Manifest tidak ditemukan atau bukan tujuan hub Anda."
}
