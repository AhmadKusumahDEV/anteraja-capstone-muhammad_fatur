# 🚀 Anteraja Hub Management System (Multi-Page App)

Folder ini berisi 5 halaman HTML & CSS terinterkoneksi sesuai spesifikasi FRD F-01 hingga F-05:

1. **`index.html`** - F-01: Autentikasi & Sesi Multi-Admin / Multi-Hub
2. **`dashboard.html`** - F-02: Hub Dashboard & Real-time Monitoring
3. **`sla-queue.html`** - F-03: Dynamic SLA Queue & Priority Reroute
4. **`outbound-dispatch.html`** - F-04: Outbound Dispatch Action & Courier Assignment
5. **`live-signaling.html`** - F-05: Real-time Event Signaling & Feeder Log
